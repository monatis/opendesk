# Cursor

Create or edit `.cursor/mcp.json` in your project root (or `~/.cursor/mcp.json` globally):

```json
{
  "mcpServers": {
    "opendesk": {
      "command": "opendesk-mcp",
      "transport": "stdio"
    }
  }
}
```

Use the full path to `opendesk-mcp` if it is not on your PATH.
